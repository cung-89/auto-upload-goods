# 淘宝商品复制与上架工具

基于 Python、Playwright 和 Tkinter 的 Windows 桌面工具。输入淘宝/天猫商品链接、店铺配置和目标类目，采集商品数据、整理 SKU 并填写卖家发布页。

## 当前状态

这是正在适配的原型。已验证一个番薯商品的编辑页填写；通用入口和跨类目实际发布尚未完成端到端验证。遇到未知页面结构或缺失属性会停止。不要视为所有类目均支持的无人值守上架产品。

## 安装和启动

需要 Windows、Python 3.11 或以上（包含 Tkinter）及 Google Chrome。

```powershell
python -m pip install -r python_copy/requirements.txt
python -X utf8 python_copy/desktop_app.py
```

也可双击 `start.bat`，无需修改项目路径。

## 使用

1. 输入商品链接、目标店铺名和完整类目路径。
2. 加载 `python_copy/shop.example.json` 并改成自己的库存、物流和价格设置。
3. 补充类目属性、图片序号、详情文字；需要时配置规格改名、排除或改价。
4. 首次使用建议点击“仅填写检查”。“填写并自动上架”会在程序校验通过后直接提交。
5. 在 Chrome 完成登录/验证码，在日志窗口按回车继续。浏览器退出前检查未保存内容。

仅处理有权使用的商品资料和素材；品牌、包装、物流及服务承诺应符合实际商品。工具不会自动清除图片内的品牌或店铺文字。

## 数据与提交记录

登录信息保存在本机 `.shop-profiles/`，运行结果在 `output/`，均已排除版本控制。仓库不包含浏览器登录状态、商品下载素材、运行截图或第三方扩展代码。

提交前创建持久化记录。同一店铺、同一来源商品已有提交记录时禁止自动重复提交；结果不明须到卖家后台核对。平台成功提示与前台标题检查不等于所有字段验证完成，规格、价格和物流仍需核对。
